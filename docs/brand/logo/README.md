# Знак Open Trader

Три концепции нового знака. Посмотреть их на тёмном и светлом фоне в размерах 16, 28, 64 и 128 px, во вкладке браузера и в шапке дашборда можно, открыв `preview.html`. Это один HTML-файл без внешних загрузок.

## Файлы

| Файл | Что это |
|---|---|
| `concept-N.svg` | знак, viewBox `0 0 32 32`, цвет `currentColor` |
| `concept-N-lockup.svg` | знак и надпись «Open Trader», viewBox `0 0 214 34`, всё в `currentColor` |
| `concept-N-favicon.svg` | favicon: плитка `#0b121a` (radius 9), знак `#4db3ff` в масштабе 0.84, как у текущего `frontend/public/favicon.svg` |
| `preview.html` | сравнение всех концепций и текущего знака |

Надпись в локапах нарисована своей геометрической монолинией (толщина 2.6, круглые концы, прописные O и T, строчные остальные) и задана SVG-контурами. Шрифт для неё не нужен и лицензий не требует. В интерфейсе подпись рядом со знаком остаётся живым текстом в `var(--font)`, так что для шапки нужен только знак.

## Концепции

**1. Проём.** Буква O разрезана пополам, правая половина сдвинута вверх и вправо. Разрыв делает кольцо открытым («Open»), ступенька вверх-вправо читается как пробой уровня («Trader»). Это две дуги с толщиной 3.5 и без мелких деталей.

**2. Бар открытия.** OHLC-бар из трёх штрихов. Левая засечка показывает цену открытия (Open), правая цену закрытия; она выше, поэтому бар растущий. Знак говорит на языке биржевого графика, и «Open» в нём буквальный.

**3. Полая свеча.** Малая сплошная свеча и правее и выше неё большая полая. На графике с полыми свечами полое тело означает рост, отсюда «открытое тело». Знак сделан заливкой, поэтому он самый плотный на 16 px.

## Рекомендация: концепция 1, «Проём»

- Только в этой концепции сразу оба слова: «Open» передан проёмом, «Trader» сдвигом вверх, и для этого не нужен ни один графический штамп.
- Знак построен на первой букве названия, поэтому он принадлежит именно Open Trader, а не любому торговому приложению. Бар и свеча встречаются в каждом терминале.
- Знак продолжает текущий (кольцо с разрывом), так что узнаваемость сохраняется, а ломаная, которая на 16 px сливалась в пятно, уходит.
- Две толстые дуги с открытыми концами на 16 px остаются чистыми в обеих темах.
- Риск: на 16 px силуэт отдалённо похож на значок «ссылка/цепь». Если владельцу это мешает, запасной вариант — концепция 2.

## Как встроить выбранный знак

Пример дан для концепции 1. Для другой концепции подставьте содержимое её `concept-N.svg`.

1. `frontend/src/shared/ui/UiLogo.vue`: заменить внутренности `<svg>` и атрибуты штриха. Обёртку (`viewBox="0 0 32 32"`, `:width`/`:height`, `aria-hidden`, класс `logo` с `color: var(--accent)`) оставить как есть.

   ```vue
   <svg class="logo" viewBox="0 0 32 32" :width="size" :height="size" aria-hidden="true"
        fill="none" stroke="currentColor" stroke-width="3.5" stroke-linecap="round">
     <path d="M13.5 10A8.5 8.5 0 0 0 13.5 27" />
     <path d="M18.5 5A8.5 8.5 0 0 1 18.5 22" />
   </svg>
   ```

   Ещё нужно обновить комментарий в `<script setup>` с описанием знака. У концепции 3 вместо `fill="none" stroke=...` ставится `fill="currentColor"` без атрибутов штриха.

2. `frontend/public/favicon.svg`: заменить файл содержимым `concept-1-favicon.svg`. Подключение в `index.html` не меняется.

3. `frontend/src/widgets/app-nav/ui/AppNav.vue` трогать не обязательно: там `<UiLogo :size="30" />` и текст `open-trader`. Если владелец захочет написание как в локапе, текст меняется на `Open Trader`. Вёрстка шапки от этого не меняется.

4. После правки открыть дашборд в тёмной и светлой теме, свернуть боковую колонку (там знак стоит один) и проверить вкладку браузера.
