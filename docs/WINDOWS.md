# Запуск на Windows

Статус: платформа используется владельцем на Windows 11 (paper и небольшие live-сделки), но покрытие меньше, чем на macOS; слабое место: остановка и перезапуск процессов (исправлено 2026-10-29, на разных машинах не проверялось). Если что-то не так, начните с раздела «Если не работает».

## Установка
1. Скопировать папку проекта целиком (`git clone` или архив; с `src\`, `config\`, `docs\`, `tests\`, `frontend\dist\`, `scripts\`; `state\` и `runtime\` по желанию, это журнал и выходы фида). Путь без кириллицы и пробелов удобнее.
2. `tb.cmd setup` в корне проекта (cmd или PowerShell). Если Python 3.9+ нет, он предложит `winget install -e --id Python.Python.3.12 --scope user`, а без winget официальный установщик python.org для текущего пользователя (без прав администратора, `PrependPath=1`); заглушка `python.exe` из WindowsApps, открывающая Store, за Python не считается. Затем проверит среду (пакет `websockets` для дашборда, порт 8765, часы, доступ к Bybit), предложит провайдера LLM и запустит платформу. Ничего не ставится без ответа «да»; посмотреть команды без выполнения: `tb.cmd setup --dry-run`. Подробно: `docs/QUICKSTART.md`, раздел 0.
3. Единственная обязательная внешняя зависимость: `websockets` (дашборд), её ставит `setup` (`pip install --user`). Node.js не нужен.
4. Часы Windows часто отстают от биржи на десятки секунд: `setup` это покажет. Синхронизация: Параметры -> Время и язык -> Дата и время -> «Синхронизировать» или `w32tm /resync /force` в PowerShell от администратора.

## Аналоги `./tb`
В корне проекта две обёртки, поведение одно (всё делает `src\tb\launcher.py`, как и `./tb` на macOS):
```
tb.cmd help                      (cmd.exe или PowerShell: .\tb.cmd help)
.\tb.ps1 help                    (PowerShell; удобнее, если в аргументах есть & | ^ %)
tb.cmd test                      все тесты
tb.cmd dash --open               дашборд на http://127.0.0.1:8765/ (наружу не слушает)
tb.cmd feed start                фид рынка
tb.cmd bybit read balance        профили read | trade | testnet, как на macOS
```
Если PowerShell не даёт запускать скрипты: `powershell -ExecutionPolicy Bypass -File .\tb.ps1 help` или используйте `tb.cmd`.
Свой интерпретатор: `set TB_PYTHON=C:\Python39\python.exe` (путь без пробелов). Корень данных можно сменить `set TB_ROOT=D:\traider-bot`.

## Где лежат ключи Bybit
Файлы: `bybit_mainnet.env` (read), `bybit_mainnet_trade.env` (trade), `bybit_testnet.env` (testnet), формат `KEY=VALUE` по строке (`BYBIT_ENV`, `BYBIT_API_KEY`, `BYBIT_API_SECRET`).
Основной каталог: `%USERPROFILE%\.config\traider-bot\` (как `~/.config/traider-bot/` на macOS), запасной: `%APPDATA%\traider-bot\`. Первый найденный файл побеждает.
Другой каталог: переменная `TB_KEYS_DIR`. Права 0600 на Windows не применимы: храните файлы в профиле своего пользователя, не в папке проекта и не в облачной синхронизации.
Файлы ключей из macOS копируются вручную, в чат и в репозиторий их не вставлять. Прокси-переменные (`HTTPS_PROXY`, `HTTP_PROXY`, `ALL_PROXY` любого регистра) и системный прокси
снимаются только для команд `bybit ...`, остальные команды окружение не меняют.

## Дашборд
`tb.cmd dash --open` откроет страницу в браузере по умолчанию; без `--open` откройте `http://127.0.0.1:8765/` сами. Порт занят: `tb.cmd dash --port 8790`.
Дашборд по умолчанию новый (Vue + WebSocket); он отдаёт готовую папку `frontend\dist` из репозитория, Node.js для запуска не нужен. Если папки нет, страница сама покажет, что делать: `npm --prefix frontend ci`, затем `npm --prefix frontend run build` (нужен Node.js).
Остановка: Ctrl+C. Страница обновляется по сокету сама и читает только файлы `state\` и `runtime\`; фид (`tb.cmd feed start`) и сканеры запускаются отдельно, без них цены и здоровье будут «устарели/нет данных».
Брандмауэр Windows спрашивать не должен: сервер слушает только 127.0.0.1.

## Что учтено в коде
- Пути через `os.path`/`paths.py`; чтение и запись файлов с `encoding="utf-8"`, консоль переключается на UTF-8 (`PYTHONUTF8=1` в обёртках и `reconfigure` в launcher).
- Атомарная запись `os.replace` на Windows падает с PermissionError, пока файл открыт читателем (дашборд читает `runtime\market.json` каждые 3 с): запись идёт через `fsutil.replace` с повторами.
- `asyncio`: `add_signal_handler` на Windows недоступен, Ctrl+C у фида ловится как исключение. Unix-only вещей (`fcntl`, `os.fork`, `sh`) в проекте нет.
- Тесты не используют жёсткие `/tmp`-пути в сравнениях.

## Если не работает
- `python не найден`: поставьте Python или задайте `TB_PYTHON`.
- Иероглифы вместо кириллицы: запускайте через `tb.cmd`/`tb.ps1` (они ставят UTF-8) или `chcp 65001`, шрифт консоли Consolas/Cascadia.
- `нет файла ключа для профиля ...`: сообщение показывает оба проверяемых пути.
- `PermissionError` при записи фида: антивирус или проводник держит файл; повторы уже есть, при частых сбоях исключите папку проекта из сканирования.
- Известный остаток: `marketdata\hotscan.py` пишет `hot.json` через прямой `os.replace` (без повторов); при редких PermissionError дашборд просто покажет прошлое значение.
