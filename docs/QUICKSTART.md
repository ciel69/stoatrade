# Быстрый старт платформы (paper)

> English overview and the shortest start: [README.md](../README.md). Подключение LLM-провайдера (любого): [PROVIDERS.ru.md](PROVIDERS.ru.md) ([EN](PROVIDERS.md)).

Всё ниже запускается в терминале из корня репозитория. Деньги не двигаются: профиль `paper` торгует на бумаге по реальным публичным ценам Bybit (аккаунт и ключ Bybit не нужны). На Windows вместо `./tb` пишите `.\tb.cmd` (cmd или PowerShell), подробности: `docs/WINDOWS.md`.
Ключи и токены нигде не печатаются, кроме токена дашборда: он показывается один раз.

## 0. Первый запуск: `./tb setup`
```
./tb setup                    # macOS, Linux, WSL
.\tb.cmd setup                # Windows
./tb setup --check            # только проверка среды и таблица «готово / нет» (без вопросов, ничего не меняет); код 1, если среда не готова
./tb setup --check --offline  # то же без обращения к api.bybit.com
./tb setup --dry-run          # показать, что было бы сделано: команды печатаются, ничего не ставится и не запускается
./tb setup --yes              # «да» на установку и запуск без вопросов (ключи без терминала не вводятся)
./tb setup --no-start         # всё, кроме запуска платформы в конце
```
Каждая установка идёт только после вопроса `[Y/n]`, точная команда печатается заранее. Без терминала и без `--yes` ничего не ставится: печатается инструкция, код 3. Повторный запуск идемпотентен: уже готовое пропускается, существующие ключи и токены не перезаписываются без явного «да».

**Этап 0, если Python нет** (делают обёртки до Python):

| ОС | что предлагается | файл |
|---|---|---|
| Windows | `winget install -e --id Python.Python.3.12 --scope user`; нет winget: официальный установщик python.org для текущего пользователя (`/quiet InstallAllUsers=0 PrependPath=1`, без прав администратора). Заглушка `python.exe` из WindowsApps (открывает Store) за Python не считается. После установки PATH обновляется в этом же окне; если не вышло, откройте новый терминал | `tb.cmd`, `tb.ps1`, `scripts/bootstrap.ps1` |
| macOS | `brew install python@3.12`; нет Homebrew: пакет python.org через `sudo installer` (спросит пароль). Заглушка `/usr/bin/python3` без Command Line Tools не вызывается | `tb`, `scripts/bootstrap.sh` |
| Linux, WSL | команда менеджера пакетов: apt, dnf, yum, pacman, zypper или apk (через `sudo`, если вы не root) | `tb`, `scripts/bootstrap.sh` |

Python стоит в нестандартном месте: `TB_PYTHON=/путь/к/python3 ./tb setup` (Windows: `set TB_PYTHON=C:\путь\python.exe`). Любая другая команда `./tb ...` без Python не падает, а подсказывает `./tb setup` (код 3).

**Этапы на Python:**
1. Проверка среды: Python 3.9+; пакет `websockets` 13+ (единственная обязательная внешняя зависимость, на ней работает дашборд; `ccxt` необязателен); собранный дашборд `frontend/dist` (лежит в репозитории, Node.js не нужен); свободный порт дашборда 8765; запись в `state/` и `runtime/`; доступ к публичному `api.bybit.com`; расхождение системных часов с часами Bybit. Нет `websockets`: предлагается `python -m pip install --user "websockets>=13"`, а у системного Python с запретом pip (PEP 668, Debian/Ubuntu, Homebrew) виртуальное окружение `.venv` в папке проекта (обёртки `./tb` подхватывают его сами).
2. Режим: paper. testnet и live мастер не включает никогда.
3. Ключ подписи, токен дашборда (печатается один раз, сохраните в менеджере паролей), токен агента `api`, по желанию ключи Bybit (`./tb setup bybit`), права файлов.
4. Мозг: пропустить; DeepSeek (ключ скрытым вводом); другой облачный провайдер (`./tb llm provider add`, ключ вводит сама команда `./tb llm key set` скрытым вводом); локальная модель (LM Studio на `127.0.0.1:1234` или Ollama на `127.0.0.1:11434`: мастер спросит список моделей у сервера и предложит команды подключения). Ключи лежат вне репозитория, в `~/.config/traider-bot/`; мастер их значений не видит и не печатает. Подробности: `docs/PROVIDERS.ru.md`.
5. Запуск платформы (`./tb start`, paper, в фоне) и дашборда в браузере.

**Часы.** Подпись запросов к Bybit поправку часов учитывает сама, но метки времени платформы (свежесть данных, срок планов, закрытие свечей) берутся с локальных часов. Расхождение больше 2 с мастер показывает предупреждением с подсказкой: Windows: Параметры -> Время и язык -> Дата и время -> «Синхронизировать» или `w32tm /resync /force` (PowerShell от администратора); macOS: «Устанавливать автоматически» в настройках даты или `sudo sntp -sS time.apple.com`; Linux: `sudo timedatectl set-ntp true` (с chrony `sudo chronyc makestep`); WSL: `sudo hwclock -s` или `wsl --shutdown`.

## 1. Проверка источников новостей (по желанию, один раз)
```
./tb intel verify          # ходит в сеть, из обычного терминала; результат: docs/spec_v2/WP13_sources.md
```
Пока источники не подтверждены (`verified:false`), новости не влияют на решения. Сервис `intel` входит в набор по умолчанию и сам деградирует; проверка P15 напоминает «источники не проверены владельцем, запусти ./tb intel verify».

## 2. Запуск платформы: одна команда
```
./tb start      # вся платформа в фоне; профиль из config/local/platform.json, иначе paper
./tb stop       # мягкая остановка;  ./tb restart = stop + start;  ./tb status = состояние
```
Всё. `start` поднимает все сервисы (`exec`, `scan`, `feed`, `context`, `intel`, `sync`, `dispatch`, `ctl`, `dash` и мозг `brain`) и печатает профиль, ссылку на дашборд и следующие шаги: открыть http://127.0.0.1:8765/ (новый дашборд, токена в нём нет), нажать «Старт».
Мозг сам не включается, пока нет условий (подписчик `api`, ключ провайдера, профиль и модель в `config/brain.json`): тогда `start` пишет одну строку «мозг выключен: причина (как включить: ...)», а остальное работает.
Порт дашборда 8765 занят другой программой: `start` не запускает платформу и подсказывает выход; `./tb start --port 8790` запоминает порт в `config/local/platform.json` (`{"svc": {"dash": {"port": 8790}}}`). Уже запущена: `start` пишет «уже запущена» и показывает ссылку (код 0). Если вы нажали Ctrl+Z и супервизор завис (состояние T), `start`, `stop`, `restart` и `down` сами пошлют ему SIGCONT и дождутся остановки;
не вышло за ~40 с: напечатают, что сделать вручную. Профиль trade (реальные деньги) через `start` не включается. Ярлык `tb-start.command` (macOS) / `tb-start.cmd` (Windows) делает то же и открывает дашборд.

## 3. Вход и старт дня
1. Откройте http://127.0.0.1:8765/: в новом дашборде вход без токена. Опасное (live, снятие KILL) включает только владелец флагами в `config/control.json` (`auth.dash2_full`, `allow_live_start_from_dash`, `allow_clear_kill_from_dash`), пока они выключены, интерфейс пишет причину. Подробно: `docs/CONTROL.md`.
2. Кнопка «Старт…» -> режим `paper`, сессия (`intraday`), минуты -> «Запустить». Старт идёт шагами S1-S9 (вкладка «День»): preflight, фактура, досье, утренний брифинг мозга, план дня, сессия, торговый флаг.
3. Жёлтые пункты preflight (старый сканер, нет свежего контекста) для paper можно принять («с замечанием»); красные блокируют старт, причина показана на вкладке «День».
4. После перезапуска платформы при идущем дне торговый флаг выключен: на вкладке «День» кнопка «Возобновить день» (только paper/testnet; для live: стоп и новый старт).

## 4. Включить живой мозг (по желанию, нужен ключ любого провайдера)
Коротко (DeepSeek или Anthropic уже в реестре; другие провайдеры, свой адрес и локальные модели: `docs/PROVIDERS.ru.md`):
1. Ключ: `./tb llm key set deepseek`. Затем `./tb llm check --live` (живой запрос на провайдера, тратит копейки) и `./tb brain probe --all --live`.
2. Включить подписчика `api` в ЛИЧНОМ слое (поставляемый `config/subscriptions.json` не трогаем, он держит `api` выключенным): выполнить `./tb brain enable` (команда сама пишет `config/local/subscriptions.json`, идемпотентна, печатает чего ещё не хватает; выключить: `./tb brain disable`). Каталог `config/local/` в `.gitignore`, файлы там глубоко сливаются поверх `config/<имя>.json` (списки с `id` по id); то же работает для `intel.json` (`sources.<id>.verified`), `platform.json`, `providers.json`, `brain.json`.
3. Перезапуск: `./tb restart` (мозг входит в набор по умолчанию и стартует, когда условия выполнены).

Кнопка «Старт» при жёлтых проверках (P10, P11, P15...) показывает их списком с причиной и действием; каждую нужно отметить, затем «Запустить с предупреждениями». Отказ различает «жёсткие условия не выполнены» (красные проверки) и «предупреждения (жёлтые) не приняты». Капитал обновляет сервис `sync` раз в 5 минут читающим ключом `read`; большое расхождение с биржей (>10%) ждёт `./tb sync confirm`.
4. `./tb brain status`, `./tb logs brain`. Утренний брифинг теперь делает модель (`morning_analyst`), события позиции разбирает `position_manager`, закрытые сделки разбирает `reviewer`, итог дня `day_auditor`.
Мозг не может открыть сделку сам: планы подаёт агент через шлюз (чат/ваш агент); мозг только сопровождает (hold, подтянуть стоп, закрыть). У агента `api` права только `paper`.

### Добавить другого провайдера LLM (OpenAI, Gemini, OpenRouter, локальный)
Полная инструкция с таблицей шаблонов и ошибками: `docs/PROVIDERS.ru.md`. Кратко:
1. Шаблоны: `./tb llm presets` (все НЕ проверены живым ключом). Добавить: `./tb llm provider add gemini --preset gemini` (провайдер выключен).
2. Ключ (в терминале, ввод скрыт): `./tb llm key set gemini`. Включить (только после ключа): `./tb llm provider enable gemini`. Проверить с ключом: `./tb llm check --provider gemini --live`; имя модели и цены поправить: `./tb llm model set gemini flash --name ИМЯ_ИЗ_GET_MODELS --price-in 0.3 --price-out 2.5`.
3. Профиль и роли: `./tb brain profile set gem-flash --provider gemini --model flash`, затем `./tb brain role chain shared.news_reader --primary gem-flash --fallback ds-flash` или `./tb brain use all gem-flash`.
4. Всё то же будет на вкладке «Настройки» дашборда (ключ вводится там в поле, обратно не показывается). Подробности: `docs/PROVIDERS.ru.md`, `docs/BRAIN.md`, `docs/spec_v2/SETTINGS_API.md`. Несколько бирж: `docs/EXCHANGES.md` (пока работает только Bybit).

## 5. Что смотреть на вкладках дашборда
Разделы в левой колонке, вкладки раздела сверху. Скриншоты каждого экрана: `README.ru.md`, `docs/images/`.

| раздел -> вкладка | что там |
|---|---|
| Обзор | деньги (под риском, запас до дневного лимита, итог дня, капитал), запас до остальных лимитов, открытые позиции со стопом и тейком, накопленный PnL, что делает мозг, лимитные заявки, планы в работе |
| Рынок -> Карта, Новости | карта монет (изменение цены, оборот, открытый интерес, фандинг, ликвидации, ордерфлоу), горячие монеты сканера; фактура новостей и календарь (после `intel`) |
| Торговля -> Сделки | накопленный PnL, история сделок, PnL по сделкам, причины выхода, теги ошибок из разбора |
| Торговля -> Планы | планы: ждут входа / далеко / в сделке / закрытые, условие входа, стоп, цели |
| Торговля -> Идеи | идеи с уровнями, их будит сканер |
| Торговля -> День | состояние дня, шаги S1-S9 и C1-C8, план дня, перенос, итог дня, «Возобновить день» |
| Торговля -> Эксперименты | гипотезы, эксперименты и варианты: n, средний R, доля прибыльных, «мало данных» |
| Мозг -> Решения, Досье | лента решений ролей и исполнителя, отказы, результат по моделям; досье, которое видит мозг (то, чего в нём нет, мозг не знает) |
| Система -> Управление | состояние платформы, остановка дня, аварийная остановка, уровень риска, узлы, сессия с бюджетом убытка, запас до лимитов, капитал |
| Система -> Настройки, Уведомления | какая модель у какой роли, провайдеры и биржа, расход LLM; уведомления ОС (по умолчанию выключены) |
| облако справа внизу | последние события шины (сигналы сканера, вехи позиции, входы, закрытия) |

## 6. Остановка
- Мягко (рекомендуется): вкладка «Управление» -> «Стоп (мягкий)». День закроется чек-листом, итог появится на вкладке «День» и в `state/days/<D-id>/report.md`.
- Платформа целиком: `./tb stop` (или `./tb down`; если открыты позиции, будет напоминание; в paper это бумага).
- Аварийно: кнопка «Аварийная остановка» (ставит KILL, при желании закрывает всё) или `./tb exec halt --flatten`. Снять KILL можно только командой `./tb exec resume`.

## 7. Если что-то не так
```
./tb status                  # сводка цветом; код 0 = платформа запущена
./tb logs                    # платформа; ./tb logs exec | scan | feed | dispatch | ctl | dash | brain  (-n 100, -f)
./tb day status              # день и причина отказа старта; ./tb day preflight --mode paper
./tb control status          # ключ, токен, права (создаются сами при ./tb start); ./tb setup --check
./tb brain status            # мозг, профили, очередь заданий
```
| проблема | что делать |
|---|---|
| `./tb: Permission denied` | архив без бита исполнения: `chmod +x tb` (или `sh tb ...`) |
| «Не найден Python 3.9 или новее» | `./tb setup` (Windows: `.\tb.cmd setup`) предложит установку; Python в другом месте: `TB_PYTHON=...` |
| дашборд не открывается, в логе `No module named 'websockets'` | `./tb setup` (предложит `pip install --user "websockets>=13"` или `.venv`) |
| порт 8765 занят | `./tb start --port 8790` (запомнится в `config/local/platform.json`) |
| «Системные часы ... отстают от Bybit» | синхронизируйте время (раздел 0, «Часы») |
| сетевые/DNS-ошибки, WebSocket не подключается | песочница, VPN или фаервол режут исходящие соединения; запускайте в обычном терминале. Прокси у сервисов биржи отключены намеренно (`docs/WINDOWS.md`, `docs/RUNBOOK.md`) |
| `мозг выключен: ...` | строка говорит причину; `docs/PROVIDERS.ru.md`, шаг 6 |

Типичное: «ctl не отвечает» -> смотрите `./tb logs ctl`; «исполнитель не жив» -> `./tb logs exec` (нет сети до Bybit; прокси у сервисов отключены намеренно); день завис в `closing` -> вкладка «День» (ответьте на вопрос о переносе или ждите 15 минут).
Проверка всей цепочки без вашего счёта: `./tb smoke` (временный корень, фейковый LLM, публичные данные Bybit; результат `docs/spec_v2/SMOKE_RESULT.md`).

## 8. Чего пока нет
- Живой модели в деле не видели: промпты и формат ответов проверены только на фейковом LLM (`docs/ROLES.md`), живой eval делает оператор.
- Рынок для досье: фид даёт BTC/ETH/SOL; медленные данные (`context.json`: деривативы, макро) отдельным сервисом не поднимаются, поэтому P10 жёлтый, а блока риска рынка в досье нет.
- Новости: источники не подтверждены, читатель новостей на живом тексте не проверялся.
- Live и testnet через платформу: только оператор (владелец счёта), по `docs/CONTROL.md` и `docs/PERMISSIONS.md`; в этом быстром старте их нет.
- Windows проверен у владельца на Windows 11 ограниченно; автозапуск ОС на живой машине не проверялся. Ветки установки Python (winget, python.org, Homebrew, менеджеры пакетов Linux) проверены только печатью команд (`--dry-run`), а не реальной установкой.

## Шпаргалка команд
```
./tb setup [--yes] [--dry-run] [--no-start]   первый запуск: среда, установка, ключи, LLM, запуск
./tb setup --check [--offline]             проверка среды и таблица готовности (ничего не меняет)
./tb setup bybit --profile read|trade|testnet   ключ биржи Bybit (скрытый ввод; нужен только для live/testnet, см. docs/EXCHANGES.md)
./tb start | stop | restart                 запуск (всё, в фоне), остановка, перезапуск
./tb status | ./tb logs [сервис] [-f]      состояние и журналы
./tb day status | day report | day preflight    день, итог, проверка перед стартом
./tb control status | token new            ключ и токен для опасных действий (создаются сами; token new = заменить)
./tb llm check [--live] | brain status     провайдеры и мозг
./tb smoke [--max-seconds N]               сквозной прогон paper во временном корне
./tb test                                  все тесты одной командой
```

## Для продвинутых (параметры запуска)
```
./tb up [--profile paper|testnet|trade] [--observe] [--services a,b,c] [--detach] [--dry-run]   старый явный запуск; без --services набор тот же, что у start
./tb down [--timeout N]                    остановка (как stop)
./tb start --profile testnet               другой профиль (trade через start не включается)
./tb start --services exec,scan,dash       свой набор сервисов (мозг отсеивается только в наборе по умолчанию)
```
Постоянный профиль: `config/local/platform.json`, например `{"profile": "testnet"}`. Профиль trade: `./tb up --profile trade --i-understand-live --detach` и шаги `docs/RUNBOOK.md`.
